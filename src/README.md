# Literatura na Escola

Bem-vindo ao projeto **Literatura na Escola**!

Este livro digital é um espaço de reflexão e compartilhamento de experiências sobre como levar a literatura de forma viva e engajadora para os nossos alunos.

Aqui discutiremos:
- Metodologias ativas na leitura.
- Curadoria de textos para o Ensino Fundamental.
- Escrita criativa e autoria.
